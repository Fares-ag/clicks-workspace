# Play Store credentials (local only)

Place these files here — they are **gitignored**:

| File | Purpose |
|------|---------|
| `service-account.json` | Google Play Developer API service account key |

Also required (not in this folder):

| File | Purpose |
|------|---------|
| `android/key.properties` | Upload keystore passwords + path |
| `android/upload-keystore.jks` | Release signing keystore |

Setup instructions: [`../PLAY_STORE.md`](../PLAY_STORE.md)
